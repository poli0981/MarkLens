# 09 · i18n

## Setup

`flutter_localizations` + `gen-l10n`. Files: `lib/l10n/app_en.arb` (source
of truth), `app_vi.arb`, `app_ja.arb`. Locale resolution: setting
`language` — `system` maps through supported locales with `en` fallback.

## Rules

1. Every user-facing string is an ARB key (CLAUDE.md rule 4) — including
   menu items, tooltips, dialogs, notices, placeholder cards ("Raw HTML
   (not rendered)", "MDX · {n} imports hidden").
2. No sentence assembly by concatenation; use placeholders and ICU plurals
   (`{count, plural, …}`) — Vietnamese and Japanese word order will break
   concatenated English fragments.
3. Key naming: `feature_element_purpose` camel-cased per gen-l10n norms,
   e.g. `readerCopyCodeTooltip`, `sidebarMissingBadge`.
4. Dates/numbers via `intl` with the active locale.
5. `en` merges first; `vi`/`ja` may trail within a PR train but must be
   complete before a release tag (release checklist, doc 15).
6. Repo documentation stays English-only.

## Layout tolerance

Vietnamese runs ~20–30% longer than English; Japanese is denser but taller.
UI must tolerate both: no fixed-width buttons around text, ellipsis +
tooltip for paths, menu bar tested in all three locales (part of the M3
DoD).
