# Contributing to MarkLens

Thanks for your interest! MarkLens is a solo-maintained project with a
strict spec — the `docs/` suite is the source of truth.

- **Open an issue first** for anything beyond a typo fix; features that
  conflict with `docs/00_CHARTER.md` non-goals (editing, sync, plugins,
  webview) will be declined kindly.
- Read `CLAUDE.md` (the ten hard rules) — they apply to humans too.
- Conventional commits; small PRs; `flutter analyze`, `dart format
  --set-exit-if-changed .`, and `flutter test` must be green.
- New user-facing strings go through ARB (`docs/09_I18N.md`); English
  required, VI/JA appreciated.
- New dependencies need a justification and rows in `docs/01_TECH_STACK.md`
  + `legal/THIRD_PARTY_NOTICES.md`.
